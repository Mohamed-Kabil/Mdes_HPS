Help

What each section does, for a new team member.

SectionRole
Comparison Compares the HPS implementation (data.yaml) against the network's current specification (e.g. pre-dig.yaml for Mastercard) and lists the gaps per endpoint (missing or divergent field). No criticality level: assessing how serious a gap is is an analyst's job.
Releases Tracks upcoming network changes (new releases) that mention the tracked endpoints, to anticipate changes before they go to production.
Email Prepares and sends a report (Comparison or Releases) by email, with the full detail attached as an Excel file.
Configuration Read-only list of the endpoints tracked for the active network.
Notes Free-text comment area attached to each endpoint, to keep a record of the team's observations over time.
